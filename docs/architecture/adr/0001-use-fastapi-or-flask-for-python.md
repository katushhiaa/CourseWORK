# 1. Вибір легковажного вебфреймворку для Python

- **Статус:** Accepted
- **Контекст:** Для розробки курсового вебсервісу на Python необхідний інструмент, що забезпечує швидкий старт, легку інтеграцію з MongoDB та автоматичну генерацію документації API.
- **Розглянуті альтернативи:**
  1. *Django + Django REST Framework:* занадто важкий, монолітний, надлишкова реляційна ORM, яка не підходить під MongoDB з коробки.
  2. *Flask:* легкий, але вимагає ручного підключення сторонніх бібліотек для валідації та OpenAPI.
  3. *FastAPI:* сучасний асинхронний фреймворк із вбудованою валідацією на базі Pydantic та автоматичним Swagger UI.
- **Рішення:** Обрати **FastAPI**
- **Наслідки:** Висока швидкість виконання запитів, автоматична документація та зручна робота з моделями даних. Пов'язано з [SDD](../sdd.md).
