# 2. Вибір MongoDB як основного сховища даних

- **Статус:** Accepted
- **Контекст:** Проєкт вимагає роботи з гнучкими, ітеративно змінюваними структурами даних без жорсткої реляційної схеми.
- **Розглянуті альтернативи:**
  1. *PostgreSQL:* класична реляційна БД, що вимагає постійних міграцій схем при зміні структури сутностей.
  2. *MongoDB:* NoSQL документо-орієнтована база даних, ідеальна для Python-додатків завдяки нативній роботі з JSON/BSON документами.
- **Рішення:** Використовувати **MongoDB**.
- **Наслідки:** Зручність збереження вкладених об'єктів, швидке прототипування, відсутність потреби у складних SQL-міграціях на етапі розробки курсової. Пов'язано з [SDD](../sdd.md) та [ISD](../isd.md).
