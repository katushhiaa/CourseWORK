# API Документація

Цей розділ відповідає за третій рівень піраміди документації (**«Як інтегруватися?»**).

Попередній перелік ендпоінтів можна переглянути у [System Design Document (SDD)](../architecture/sdd.md). Повна специфікація OpenAPI, описи ендпоінтів, схеми запитів/відповідей та приклади інтеграції будуть додані на наступному етапі роботи з контрактами API.
